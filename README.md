# Castillo de las Letras

App web para que una niña aprenda a leer en español, con princesas, juegos cortos y avance por días.

- **Parte 1** (21 días): vocales y sílabas básicas (M, P, S, L, T, N, D, C, B, V, F, R, RR, Ñ, CH, LL).
- **Parte 2** (18 días): G, GUE/GUI, QUE/QUI, J, Z, CE/CI, GE/GI, H, Y y sílabas de tres letras (TR, BR, PL, BL, GR, FR).
- Cada pantalla lee la instrucción en voz alta y tiene un botón 🔊 para repetirla.
- Panel "Para papá y mamá": elegir voz y velocidad, código de respaldo para pasar el avance a otro aparato.

Es un solo archivo (`index.html`), sin servidor ni cuentas. El avance se guarda en el navegador de cada aparato.
